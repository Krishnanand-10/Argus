CLI Interface

Everything you need from your terminal.

Index directories, query compressed binary indexes, inspect dictionary statistics, or run a high-throughput REST server. 

# Ingest markdown, JSON, or text documents into compressed .argus binary index
$ argus index --source ./docs --output ./indices/docs.argus

✔ Scanned 10,480 document(s) in 342ms
✔ Inverted index compiled (28,140 unique lexicon stems)
✔ Serialized to docs.argus (12.4 MB · 71.4% compression vs raw JSON)
# Execute an instant query with full boolean & phrase syntax
$ argus search --index ./docs.argus "distributed AND consensus NOT byzantine"

Architecture

Everything Elasticsearch does, minus the Java runtime.

Engineered from first principles with zero third-party dependencies, contiguous typed memory buffers, and mechanical sympathy for V8.

Zero Dependencies

Zero External Dependencies

100% handwritten from first principles. Tokenizers, stemmers, compression codecs, and data structures contain zero third-party packages and require no native C++ compilation.

Zero Bloat Cross-Platform Node & Bun Native
V8 Optimization

Mechanical Sympathy for V8

Operates on contiguous typed buffers (`Uint8Array`, `Uint32Array`, `Float32Array`) rather than millions of fragmented objects, eliminating GC latency.

TypedArrays Zero-GC Pauses Cache Locality
Query Parsing

Positional Phrase & AST Engine

Recursive-descent query grammar parser supporting parentheses, boolean algebra (`AND`, `OR`, `NOT`), wildcards, and exact positional phrase distances.

Boolean Algebra Exact Quotes Slop Verification
Persistence

Proprietary .argus Binary Format

Serializes indexes with magic headers (`0x41 0x52 0x47 0x53`), Delta d-gaps, Variable-Byte (Varint) continuation bits, and CRC32 verification (65%–75% reduction vs JSON).

VByte Codec Delta D-Gaps Zero-Copy Read
Retrieval Speed

Skip Lists & WAND Pruning

Skip pointers placed every ⌊√L⌋ entries enable jumping over large blocks of non-matching documents. Dynamic WAND skips non-competitive documents early.

WAND Pruning Skip Lists MinHeap Top-K
Delivery

Dual CLI & Embedded REST Daemon

Includes a native zero-dependency HTTP search server with REST endpoints (`/api/search`), dynamic JSON ingestion, and interactive CLI tooling out of the box.

REST API Interactive CLI Embeddable SDK
System Design

Decoupled Ingestion & Query Pipeline

Argus cleanly separates the write path (tokenization, stemmer, lexicon, delta compression) from the read path (AST parser, skip pointers, BM25 scorer).

Ingestion Pipeline (Write Path)
01
Raw Document Parser
Streams JSON, Markdown, or plain text corpora
02
Unicode NFKD & Lexer
Extracts word boundaries and byte offsets
03
Porter Stemmer & Stopwords
Morphological reduction & 170 stopword filtering
04
Delta & Varint Compression
Monotonic doc IDs encoded with 7-bit continuation
05
.argus Binary Serialization
Magic bytes (0x41 0x52 0x47 0x53) + CRC32 verification
Query Engine (Read Path)
01
AST Lexer & Parser
Builds execution tree for AND, OR, NOT, and phrases
02
Lexicon Dictionary Lookup
O(1) Radix trie retrieval of posting byte offsets
03
Skip-List Intersector
Leaps across postings blocks in O(min(N,M)) time
04
Okapi BM25 Scorer
Term saturation (k1) + length penalty (b) + Robertson IDF
05
MinHeap Top-K Collector
Extracts highest-scoring documents without sorting
